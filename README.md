# Awesome THETA [![Awesome](https://cdn.rawgit.com/sindresorhus/awesome/d7305f38d29fed78fa85652e3a63e154dd8e8829/media/badge.svg)](https://github.com/sindresorhus/awesome)

A curated list of awesome things related to [RICOH THETA](https://www.ricoh360.com/theta/)

## :link: THETA API

- [RICOH360 Docs for Developers](https://docs.ricoh360.com/)
- [theta-api-specs](https://github.com/ricohapi/theta-api-specs) - RICOH THETA API specifications

## :iphone: THETA Mobile SDK and Library

- [theta-client](https://github.com/ricohapi/theta-client) - Client library using Web API v2.1 to control THETA
- [theta-ble-client](https://github.com/ricohapi/theta-ble-client) - Client library using Bluetooth API to control THETA
- [fake-theta](https://github.com/ricohapi/fake-theta) - THETA Web API response simulator
- [theta-api2.1-ios-sdk](https://github.com/ricohapi/theta-api2.1-ios-sdk) - [archived] A sample application project using Web API v2.1 for iOS
- [theta-api2.1-android-sdk](https://github.com/ricohapi/theta-api2.1-android-sdk) - [archived] A sample application project using Web API v2.1 for Android

## :electric_plug: THETA Plugin

- [theta-plugin-library](https://github.com/ricohapi/theta-plugin-library) - Library including THETA specified methods and APIs
- [theta-plugin-sdk](https://github.com/ricohapi/theta-plugin-sdk) - Sample project
- [theta-plugin-camera-api-sample](https://github.com/ricohapi/theta-plugin-camera-api-sample) - Sample project of Camera API usage
- [theta-plugin-camera-api-sample-x](https://github.com/ricohapi/theta-plugin-camera-api-sample-x) - Sample project of Camera API usage for RICOH THETA X
- [theta-automatic-face-blur-plugin](https://github.com/ricohapi/theta-automatic-face-blur-plugin) - Automatic face blur plugin
- [theta-wireless-live-streaming-plugin](https://github.com/ricohapi/theta-wireless-live-streaming-plugin) - Wireless live streaming plugin
- [theta-cloud-upload-v2-plugin](https://github.com/ricohapi/theta-cloud-upload-v2-plugin) - File cloud upload V2 plugin
- [theta-vr-media-connection-plugin](https://github.com/ricohapi/theta-vr-media-connection-plugin) - VR media connection plugin
